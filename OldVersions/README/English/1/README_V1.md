# CamCamPlus Moire Rate

`📷️📸️➕️🖥️🤳️💾️ THe official source repository for the CamCamPlus MoireRate extension, enabling high quality screen on screen recording, without all of the artifacts.`

[:octocat: `Home repository`](https://github.com/seanpm2001/CamCamPlus/)

***

## Purpose

The goal of this part of the CamCamPlus camera is to be able to take pictures of a screen using your camera, without the [Moire effect](https://en.wikipedia.org/wiki/Moir%C3%A9_pattern) reducing the quality. Machine learning, and lots of patterns will be involved to make it so that each picture or video you take of a screen will be a flawless version of what is on screen. This will expand the [analog hole](https://en.wikipedia.org/wiki/Analog_hole)

For now, a lot more research and experimentation is needed, and eventually, the goal will be met.
